# F1nancer — Downloads

Official builds of **F1nancer**, an offline-first personal finance app: income and
expenses, budgets, savings goals, recurring payments and simple charts. Sign in with
an email and password and the same account syncs across your devices; each device
keeps a local copy and works fully offline.

This repository hosts the release artifacts only.

## Android

Download `F1nancer-<version>.apk` from the
[latest release](https://github.com/MrEug3n1o/f1nancer-releases/releases/latest) and
sideload it. Android asks you to allow installs from whichever browser or file
manager you open the APK with. The app checks this repository for newer releases.

## Web

There is no desktop download. The web app at **https://f1nancer.web.app** replaces
the former Windows and macOS builds: open it in any browser, or install it from the
address bar for an app window and offline use.

Releases up to `v0.1.36` still carry `.exe` and `.dmg` assets. Those desktop builds
are no longer maintained.
